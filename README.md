# Sun Courier

A browser game in chapters, built with Three.js and Vite. You ride a bicycle through cities
built from famous paintings, collect what has fallen into the streets and deliver it before dawn.

1. **Castle and Sun** – a city built from Paul Klee's painting.
2. **Café Terrace at Night** – Van Gogh's Arles at night.

## Run it

```bash
npm install
npm run dev
```

Open the address it prints. Choose a chapter on the title screen, or add `?chapter=2` to the address.

## Paintings

`public/castle-and-sun.jpg` (Paul Klee, 1928) and `public/cafe-terrace-at-night.jpg`
(Vincent van Gogh, 1888) are public-domain reproductions from Wikimedia Commons.
